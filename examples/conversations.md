# Example 1 — Artificial Intelligence

## User

```text
What is Artificial Intelligence?
```

## Assistant

```text
Artificial Intelligence (AI) refers to computer systems capable of performing tasks that normally require human intelligence, such as reasoning, learning, problem-solving and decision-making.

AI is widely used in recommendation systems, chatbots, image recognition and automation technologies.
```

# Example 2 — Programming

## User

```text
Explain what Python is.
```

## Assistant

```text
Python is a high-level programming language known for its simple syntax and readability.

It is widely used in web development, automation, data science, artificial intelligence and software development.
```

# Example 3 — History

## User

```text
Who was Albert Einstein?
```

## Assistant

```text
Albert Einstein was a theoretical physicist best known for developing the theory of relativity.

He is considered one of the most influential scientists in modern history and received the Nobel Prize in Physics in 1921.
```

# Example 4 — Technology

## User

```text
What is cloud computing?
```

## Assistant

```text
Cloud computing is the delivery of computing services such as servers, storage, databases and software over the internet.

It allows users and companies to access technology resources without maintaining physical infrastructure locally.
```

## User

```text

```

## Assistant
